# Tienda Virtual — frontend

Aplicación Next.js de la tienda (catálogo, carrito, checkout, cuenta, PQRS y administración). La descripción del proyecto, cómo correrlo y cómo se construyó están en el [README principal](../README.md).

```bash
cp .env.example .env.local
npm install
npm run dev     # http://localhost:3000
```
